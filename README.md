# 个人简历作品集 Web 应用

一个美观且功能完善的个人简历制作工具，支持实时编辑、预览、导出多种格式。

## 功能特性

### 📝 核心功能
- **基本信息管理**：个人资料、联系方式、头像上传
- **教育经历**：时间线展示，支持添加/删除/排序
- **项目经历**：项目列表、详情编辑、文件上传、项目标签
- **校园经历**：组织经历、工作内容
- **个人技能**：技能分类、星级评分

### 📄 导出功能
- 导出为 PDF
- 导出为 Word (.docx)
- 导出为 JSON 备份
- 单个项目导出

### 🔄 版本控制
- 自动保存最近 10 个版本
- 支持一键回退到任意历史版本
- 版本时间戳记录

### 💾 数据管理
- 本地 localStorage 存储
- 自动保存（每 30 秒）
- 数据导入/导出 JSON

### 📱 响应式设计
- 桌面端：左右分栏布局
- 平板/移动端：响应式适配

## 快速开始

### 方法一：直接打开 (推荐)

直接用浏览器打开 `index.html` 文件即可使用。

### 方法二：本地服务器

#### 使用 Python 3:

```bash
python3 -m http.server 8080
```

#### 使用 Node.js (http-server):

```bash
npx http-server -p 8080
```

然后在浏览器中访问：`http://localhost:8080`

## 使用说明

### 1. 编辑个人信息
点击左侧导航栏的各个模块，填写对应信息。所有修改会自动保存。

### 2. 管理项目
在项目经历模块，点击「添加项目」创建新项目，点击列表中的项目进行编辑。

### 3. 版本回退
点击顶部的「版本历史」按钮，查看历史版本，点击任意版本即可回退。

### 4. 导出简历
点击顶部导出按钮，选择导出格式（PDF/Word/JSON）。

## 技术栈

- **前端框架**：原生 HTML + JavaScript
- **样式框架**：Tailwind CSS
- **UI 图标**：Font Awesome
- **拖拽排序**：Sortable.js
- **PDF 导出**：html2pdf.js
- **Word 导出**：docx.js
- **字体**：Noto Serif SC + Noto Sans SC

## 浏览器支持

- Chrome (推荐)
- Firefox
- Safari
- Edge

## 数据存储

所有数据存储在浏览器的 localStorage 中，刷新页面数据不会丢失。

为了确保数据安全，建议定期点击「保存」或「导出JSON」进行备份。
